# mini OS

**現代の肥大化したOSへのアンチテーゼ。**  
グラフィックボード（GPU）を一切要求せず、ハードウェア本来のメモリをユーザーに明け渡す超軽量デスクトップOSです。

---

## 💡 なぜ mini OS なのか？
* **一般的なWindows**: 16GBのRAMがあっても、OSだけで **3.5GB** 持っていかれ、使えるのは実質12GB強。
* **mini OS**: 将来的に機能を拡張しまくったとしても **OS消費は最大1GB**（通常は数十MB〜100MB）。  
  **👉 16GBのパソコンなら、15GB丸ごと自分の作業やアプリのために使えます。**

---

## ✨ 主な特徴
- **GPUフリー**: 専用グラボや3Dアクセラレーションは不要。CPUのソフトウェア描画だけで滑らかに動作。
- **Live USB & 永続化**: USBを挿すだけでPC本体を汚さずRAM上で爆速起動。作った成果物や設定はUSB内にしっかり保存。
- **Mac風マウス操作**: 画面上部のメニューバーと下部のDockランチャーで直感的に操作可能。
- **デュアルテーマ**: ライトモードとダークモードの両対応（ショートカットで0秒切り替え）。
- **日本語標準対応**: 日本語の表示・軽量入力システムを標準搭載。
- **Wi-Fi両対応**: 自宅Wi-Fiは自動接続、出先では画面から選んで接続。
- **デュアルブラウザ**: 普段の調べ物は爆速軽量ブラウザ（NetSurf）、動画やGoogleサービス用には現代ブラウザ（Falkon）を使い分け。
- **マルチアーキテクチャ**: 一般的なPC（x86_64）とARM（aarch64）の両方に対応。
